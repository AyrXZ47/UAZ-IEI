# UAZ - Ingeniería Electrónica Industrial con especialidad en Telecomunicaciones
### Arnold Yovick Rios Zaldivar | Academic Repository

Este repositorio centraliza mi trayectoria académica en la **Unidad Académica de Ingeniería Eléctrica de la UAZ**. Aquí se documentan proyectos de software, diseños de hardware, simulaciones y reportes técnicos organizados por semestre y materia.

## 📂 Estructura del Repositorio

A partir del 5to semestre, el contenido se organiza de la siguiente manera:

* **`5-Semestre/`**
    * `[Nombre-Materia]/`
        * `firmware/` (Código para MCU, PLC, etc.)
        * `hardware/` (Diseños en KiCad/FreeCAD)
        * `docs/` (Reportes en LaTeX, hojas de datos)
